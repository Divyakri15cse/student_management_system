# Student Management System 🎓

A simple Python-based Student Management System that uses file handling to perform CRUD operations on student records.

## Features

- ➕ Add student records
- 📋 Display all student records
- 🔍 Search student records by roll number
- 🗑️ Delete student records
- ✏️ Update student records
- 💾 Stores data using file handling

## Technologies Used

- Python
- File Handling
- OS Module

## CRUD Operations

- **Create** – Add a new student record
- **Read** – View and search student records
- **Update** – Modify an existing record
- **Delete** – Remove a student record

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Run the program:

   `python student_management_system.py`

4. Choose an option from the menu.

## Data Fields

- Roll Number
- Name
- Course
- Fee
